## Task 6: Host a Static Website with GitHub Pages



## Project Overview



This project demonstrates how to build and deploy a static website using GitHub Pages.



## Technologies Used



- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages



## Features



- Responsive navigation
- Personal introduction
- Skills section
- GitHub profile link
- Custom CSS styling



## Project Structure




## Deployment



The website is deployed using GitHub Pages from the `main` branch and the root folder.



## Learning Outcomes


- Creating a static website using HTML and CSS.
- Managing project files using Git.
- Hosting a website for free with GitHub Pages.
- Understanding static website deployment.
